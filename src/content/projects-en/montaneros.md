Montañeros is a tourism directory I built for a school project: the frontend is built with Next.js and
the content is managed from a Payload backend/CMS
([backend repo](https://github.com/sga-encoder/montaneros-cms)).

It was a technically challenging project for me at the time, but I ended up very happy with the final
result.
